# 📜 Licenser (`licenser`)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Python: 3.8+](https://img.shields.io/badge/Python-3.8%2B-brightgreen.svg)](https://www.python.org/)
[![100% Local CLI](https://img.shields.io/badge/Architecture-100%25%20Local%20CLI-brightgreen.svg)](https://github.com/MochErik/licenser)

> **Automated Open-Source License Generator (MIT, Apache, GPL, BSD) CLI.** Buat file `LICENSE` proyek open-source secara otomatis dengan nama author dan tahun terkini.

---

## 🌟 Fitur Utama
- 📝 **Template Standar Industri**: Menyediakan teks lisensi MIT, Apache 2.0, BSD-3, dan GPLv3.
- ⚡ **Auto-Year & Author Injection**: Mengisi nama pemilik dan tahun secara otomatis tanpa edit manual.
- 📁 **Instant File Creation**: Menuliskan langsung file `LICENSE` di direktori proyek.

---

## 🚀 Quick Install
```bash
pip install git+https://github.com/MochErik/licenser.git
```

---

## 🖥️ Contoh Penggunaan
```bash
# Generate file LICENSE berlisensi MIT
licenser -a "Moch. Erik Irriansyah"

# Generate lisensi Apache
licenser -t apache -a "Moch. Erik Irriansyah"
```
